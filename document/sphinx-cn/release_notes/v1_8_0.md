# v1.8.0

**⭐️ 重要功能**

- 新增 `agi_header_plugin`，支持在运行时自动检测并填充：
  - `AgiHeader`（Channel 发布消息）
  - `AgiRequestHeader`（RPC Client 请求）

**✨ 次要功能和优化**

- `agi_header_plugin` 引入 wrapper 扩展元数据缓存检测结果，减少热路径重复检测与查表开销。
- 补充插件教程文档：
  - `document/sphinx-cn/tutorials/plugins/agi_header_plugin.md`
  - `document/sphinx-en/tutorials/plugins/agi_header_plugin.md`

**🐛Bug 修复**

- 修复 `record_playback_plugin` 在 signal record 模式下 `record_duration_s` 为 0 时未持续录制的问题。
