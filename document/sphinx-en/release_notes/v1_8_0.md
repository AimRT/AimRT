# v1.8.0

**⭐️ Major Feature**

- Added `agi_header_plugin` to automatically detect and fill:
  - `AgiHeader` (Channel publish messages)
  - `AgiRequestHeader` (RPC client requests)

**✨ Minor Features and Optimizations**

- Added wrapper extension metadata caching in `agi_header_plugin` to reduce repeated detection and map lookup overhead on hot paths.
- Added plugin tutorial docs:
  - `document/sphinx-cn/tutorials/plugins/agi_header_plugin.md`
  - `document/sphinx-en/tutorials/plugins/agi_header_plugin.md`

**🐛 Bug Fixes**

- Fixed `record_playback_plugin` not recording continuously when `record_duration_s` is 0 in signal record mode.
